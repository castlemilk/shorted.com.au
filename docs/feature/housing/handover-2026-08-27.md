### 1. Merge #505 — columnar map delivery — ✅ DONE

### 2. Fix the Census ingest — ✅ PARSER DONE, ingest not yet re-run

`-mode census` ran against prod and left all seven expanded metrics NULL, logging
each miss. **No bad data was written** — the parser resolves columns by header
NAME, so a wrong table degrades to nulls rather than plausible nonsense. That
property is preserved; do not weaken it.

**The mapping in the first draft of this handover was itself partly wrong.**
Re-verified 2026-08-27 by extracting every header line from the real
short-header DataPack (`2021_GCP_SAL_for_AUS_short-header.zip`, 98 MB) rather
than reasoning from table numbers. What shipped:

| Metric | Table | Columns |
|---|---|---|
| Tenure + dwelling count | **G37** | `O_OR_Total`, `O_MTG_Total`, `R_Tot_Total` / `Total_Total` |
| Labour force | **G43** | `lfs_Unmplyed_lookng_for_wrk_P` / `lfs_Tot_LF_P`; `lfs_Tot_LF_P` / `P_15_yrs_over_P` |
| Education | **G43** | `non_sch_qual_{PostGrad_Dgre,Gr_Dip_Gr_Crt,Bchelr_Degree}_P` / `P_15_yrs_over_P` |
| Dwelling structure | **G36** | `OPDs_Separate_house_Dwellings`, `OPDs_Flt_apart_Tot_Dwgs` / `OPDs_Tot_OPDs_Dwellings` |
| Household composition | **G42** | `Tot_FHs_CF_C`, `Tot_Lone_P_H` / `Tot_Tot` |
| Personal income | **G17B + G17C** | `P_1_149_Tot`…`P_400_499_Tot` (G17B), `P_2000_2999_Tot`…`P_3500_more_Tot` (G17C) / `P_Tot_Tot` (G17C) |

Three corrections to the earlier draft, each of which removed work rather than
adding it:

1. **Education is a direct total in G43**, not an age × sex sum from G49A/B. G43
   carries `non_sch_qual_*_P` whole-of-suburb person totals alongside labour
   force. G49A/B is not needed at all.
2. **Personal income needs no summing either.** G17B/G17C carry direct `P_*_Tot`
   band totals — the *original column names in the code were already right*, only
   the table entry (bare `G17`) was wrong.
3. **G26A/B is unpaid child care, not family composition.** The household shares
   come from **G42** ("dwelling structure by household composition") as direct
   household totals.

Net: **no age × sex summing is required for any metric**, which removes the
"a missed column silently understates a share" risk entirely.

The one real complication: the low-income numerators live in G17B while the
denominator `P_Tot_Tot` lives in G17C, so that metric needs a two-file union
keyed on `SAL_CODE_2021` (`combineG17Rows`). A header colliding across the two
files is omitted rather than resolved, so any metric depending on it goes NULL.

Verified against the real DataPack — `TestExpandedCensusRealDataPack`
(skipped unless `CENSUS_DATAPACK_PATH` is set) asserts all 13 fields are
non-NULL for Bondi/Toorak/Ipswich, and the values were independently
recomputed from the raw CSVs and matched to 2dp:

| | Bondi | Toorak | Ipswich |
|---|---|---|---|
| bachelor+ | 51.95% | 51.56% | 16.23% |
| flat/apartment | 79.59% | 49.83% | 15.04% |
| rented | 56.80% | 31.11% | 54.99% |
| unemployment | 4.23% | 3.71% | 11.83% |

Sanity signal worth reusing: outright + mortgage + rented lands on 96.3–96.6%
across all three (the remainder is "other tenure" + "not stated"), which is what
a correct denominator looks like.

### 3. Make a failed ingest fail loudly — ✅ DONE

Eleven modes — `census`, `electorates`, `banners`, `amenities`, `elevation`,
`lga`, `connectivity`, `funding`, `council-financials`, `crime`,
`backfill-address` — now return `error` and dispatch through `ingestExit`, so a
failed ingest exits 1 instead of 0. Guarded by
`TestOperatorIngestModesPropagateFailure` (AST assertion on the dispatch shape).
Full detail in [pipeline.md](pipeline.md#operator-ingest-modes-propagate-failure-2026-08-27).

**One claim in the first draft was overstated.** `-mode census` is not scheduled
in Cloud Run *at all* — `terraform/modules/house-price-collector` schedules only
`-mode all` (monthly) and `-mode drop-index` (daily). So no Cloud Run scheduler
was sitting green on a failing census; it is operator-run, and the exit code
matters for launchd/shell wrappers. The boundary TopoJSON was therefore **not**
shipped into the image: that is 5 MB added to a build context that does not
currently include `web/`, for a mode nothing schedules. `readSuburbRegistry`
already returns a clear per-file error, which now reaches the exit code.

Operator run (how the 08-27 run was done):

```bash
cd services/house-price-collector
DATABASE_URL="$PROD" \
CENSUS_GEO_DIR=/Users/benebsworth/projects/shorted/web/public/geo/suburbs \
GOWORK=off go run . -mode census
```

### 4. Process the elevation DEM

Schema and pipeline merged, no data. Needs the Geoscience Australia 1 Second
DEM-S raster (multi-GB, CC-BY-4.0, via ELVIS) mosaicked, then
`web/scripts/geo/ga_dem_zonal_stats.py` over ~15k suburb polygons. Real compute —
schedule it rather than squeezing it in.

DEM-S is **EGM96 orthometric, not AHD**; the script does no datum conversion by
design. DEM no-data cells are excluded from numerator and denominator — counting
them as elevation 0 would fabricate low-lying land.

## Two bugs that were shipping wrong numbers (both fixed)

- **#499 — capital medians showed unit prices.** ABS regional rows carry both
  `established_house` and `attached` for the same quarter; the query broke the
  tie arbitrarily and returned units. Greater Sydney read **$848,000 against a
  real $1,485,000** (43% understated). Fixed by filtering
  `dwelling_type IN ('house','established_house')`.
- **#500 — 13 years of history discarded.** The collector requested `RES_DWELL`
  from 2015-Q1 while ABS publishes from **2002-Q1**, dropping 52 quarters for
  every region. Greater Brisbane now runs $185k (2002) → $1.15m (2026).

## Settled — do not reopen

- **School rankings from ACARA / My School.** No open licence at all; clause
  7.1(b) prohibits comparative school-performance lists for a **commercial
  purpose**; clause 6.4 bars republishing on a public website even for permitted
  non-commercial use. ABS SEIFA is the licensable substitute and is what ICSEA
  derives from. Recorded in [data-sources.md](data-sources.md) under OUT.
- **Suburb-level prices for QLD/WA/TAS/NT/ACT.** QLD's open portal has valuation
  boundaries but no prices; QLD and WA sell sales data through brokers.
  Commercially blocked, not unbuilt. The GCCSA tier covers those states instead.
- **Flood risk / likelihood per suburb.** Elevation cannot express it — flood risk
  depends on riverine hydrology, storm surge, drainage and levees. Publish
  "share of land below 2 m", a measured terrain fact. The vocabulary ban is
  enforced in column names and identifiers, not just prose.

## Upstash is at its command cap (found 2026-08-27)

The mandatory post-promote sweep (`task deploy:revalidate CONFIRM=prod`) came
back with the ISR paths revalidated but the Redis flush refused:

```
"flushErrors": ["cache:housing:: ERR max requests limit exceeded.
                Limit: 500000, Usage: 500000"]
```

Read the response body carefully: `revalidated` reflects **only** `flushErrors`.
`revalidatePath` runs before the flush loop, so the ISR pages *were* busted; what
failed is the KV layer. `HOUSING_TTL` is 24h, so staleness is bounded and then
degrades to a correct-but-slower cache-miss path. The site is not down.

This is the same failure mode as the 2026-08-21 incident recorded in the root
`CLAUDE.md` — Upstash rejects writes while still serving reads, so a stale cache
looks healthy. The fix that came out of that incident moved *rate limiting* off
Upstash (to Postgres) specifically so the page cache would fit inside 500k/month.
**If usage genuinely re-accrued within a week, that fix did not achieve its
goal and the page cache alone is over budget.**

Unresolved, and it needs Upstash console/management-API access to settle: the
billing-period reset date and the usage curve. Until that is known you cannot
tell "the August exhaustion simply has not reset" from "we are burning 500k/month
on the page cache alone", and those have completely different remedies.

## Operational notes

- **Prod does not run `migrate up`** — hardcoded allowlist, zero housing
  migrations. Apply housing DDL by hand via the **session pooler (5432)** with
  `statement_timeout=0`, **before** merging code that reads the columns, or every
  housing read path 500s. `000113`–`000115` are applied; next free is `000116`.
- **Codex agents have no network**: `buf generate` and `mockgen` are the
  coordinator's job. Widening `ShortsStore` requires regenerating the mock
  (`go generate ./...` in `services/shorts/internal/services/shorts`).
- **Parallel agents trip the pre-push hook**, which lints the whole working tree
  including their half-written files. Verify your own commit's contents before
  bypassing.
- **Stacked PRs auto-close** when the base branch is deleted on merge (#503 was
  lost that way, reopened as #504).
