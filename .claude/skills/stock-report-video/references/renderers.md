# Renderer adapters

Select the renderer requested by the user or already used by the project. These are execution adapters under the same editorial and QA contract, not two competing skill copies. Inspect the installed version, local commands and licensing before running software; no renderer switch should bypass an access or approval restriction.

## Kinetograph

Official project: https://github.com/0xS4N4TG/kinetograph . Read its installed skill at `packages/cli/skills/kinetograph/SKILL.md` and actual CLI help. Pin the version used in the project and record it. Do not copy an installation command or renderer API from a stale transcript. Its licence may impose commercial-use conditions: verify the current terms and the user's eligibility before adoption, rather than assuming an open repository means unrestricted use.

Use native text, shapes, images, sequences and audio supported by that version. Data graphics must bind to the verified claim ledger. Give persistent audio clips stable identities; verify clip count and timing instead of assuming component rerenders are harmless. Keep scene-local timing explicit and test crossfades at both boundaries.

Run the available type/check, lint, frame-strip and diagnostic commands before full render. Sample a representative motion-and-audio clip. Inspect final decode, durations and loudness independently with FFmpeg, even if the renderer says `audio=true`. Save the renderer's version, command and logs with the project. If only CPU/software rendering is available, reduce proof resolution and estimate full render time; don't claim GPU acceleration or alter system security to obtain it.

## Existing results studio

Read [studio-adapter.md](studio-adapter.md) only when using the existing OpenMontage-based `shorted-results` pack. Its schema, binding gates, approval state and CLI are adapter-specific. Resolve the actual studio location on the selected executor. A path on the owner's Mac is not available in a cloud container by implication.

Keep the studio's stage invariants and approval gates. Changes to a source, storyboard, asset or voice invalidate dependent stages. Do not blindly retry stages with uncertain side effects. Inspect actual state and cached takes first. The skill itself does not install, upgrade or migrate OpenMontage code into this repository.

For a new renderer, retain these artifacts: claim ledger, production plan, original/prompts/asset manifest, timed narration, captions, reusable layout/motion components, final export and QA receipt. Never lower evidence or playback standards to satisfy an adapter.
