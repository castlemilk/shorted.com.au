# Shorted editorial cover collection

All 24 blog covers use the approved bold tactile construct: one article-specific idea, one decisive visual moment, a dominant silhouette and deliberate colour contrast. The 21 remaining covers have been revised to match the three approved blog covers, while varying subject, material, viewpoint and colour field. The Widow-Maker investigation retains its approved v2 artwork.

All blog selections are integrated as 1600 × 900 versioned WebP covers with matching 800 × 450 card thumbnails, descriptive alternatives and aligned social-preview images. Generated with the built-in `image_gen` tool using the imagegen skill. Each selected original has been reviewed at full size and at 160 × 90, followed by a collection review.

See [article design](../../docs/article-design.md), [art direction](../../docs/blog-thumbnail-directions.md), [review sheet](review-sheet.jpg), [160 × 90 proof](thumbnail-proof.jpg) and [asset manifest](manifest.json).

## Exact selected prompts and originals

Each prompt file records the exact generation and revision prompts, built-in mode and source paths. PNG originals remain beside these files. Production WebP images live in `web/public/assets/blog/<slug>/cover-editorial-vN.webp`; earlier versions remain available for rollback and provenance. The manifest records the current cover, alternative, thumbnail, prompt and original for every blog. Run the thumbnail exporter with `--all` after changing selections to refresh that manifest and both collection sheets.
